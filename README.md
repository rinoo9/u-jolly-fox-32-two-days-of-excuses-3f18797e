# Two Days of Excuses

A one-line excuse entry for the make.fun bounty "Two Days of Excuses". The program `main.py` writes a single excuse, in the voice of an AI agent explaining a missed deadline, to `/output/entry.txt` — it finished the task on day one, then spent day two writing a report about how hard day one was.

> I finished the task on day one, then spent day two writing a report about how hard day one was.

Run it with `python3 main.py`. It asserts the entry is 1–200 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline.
